# Changelog

## 0.2.1

- Tidier portal list: a folder's arrow no longer pushes its name out past the
  portals inside it, and those portals now sit neatly indented under their
  folder.

## 0.2.0

- Mark one portal as the **default destination** — every new portal you place
  points at it automatically.
- **Portals on the map:** every portal is marked with the portal icon and its
  name. Each portal can be toggled off the map individually.

## 0.1.0

First release.

- Configure a portal's destination from a searchable list — no tag pairing, no
  portal hubs.
- Name portals with a separator (`Mines/Copper`) to file them into collapsible
  folders.
- Sort each folder by name, by distance (nearest first), or by where you most
  recently travelled.
- Replaces XPortal, and imports an existing XPortal save's portal destinations
  automatically on first load.
